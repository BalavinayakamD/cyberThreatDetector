# cyberThreatDetector

This project is a learning-focused implementation of a cyber threat detection system
using classical machine learning techniques.

The goal of this repository is not to claim production-grade intrusion detection,
but to build a strong, practical understanding of how machine learning models behave
on real-world network security data.

The project uses publicly available intrusion detection datasets to explore:
- how network traffic features are represented
- how supervised and unsupervised ML models perform on noisy, imbalanced data
- how model evaluation metrics like precision and recall matter in security contexts

The emphasis is on explainability, algorithmic understanding, and correct ML workflow
rather than deep learning or black-box models.

This repository is intended as:
- a learning artifact for classical ML
- a portfolio project for entry-level ML / SOC-related roles
- a base for further experimentation and improvement
